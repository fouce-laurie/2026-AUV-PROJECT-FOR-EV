# 两个节点功能简述

## 1. microros_bridge.py（桥接节点/传话筒节点）

### 核心功能
**双向协议转换器** - 在原始串口协议和 micro-ROS 话题协议之间进行实时翻译

### 主要职责

#### 上行转换（上位机 → micro-ROS）
```
原始话题                    →  转换  →  micro-ROS话题
─────────────────────────────────────────────────────
openloop_thrust (推力控制)   →        /zit6/cmd/setpoint (FORCE模式)
target_pos_down (位置控制)   →        /zit6/cmd/setpoint (POS模式)
Target_speed_down (速度控制) →        /zit6/cmd/setpoint (VEL模式)
pid_params_set (PID参数)     →        /zit6/cmd/pid
servo_control (舵机)         →        /zit6/cmd/servo
led_controllers (LED)        →        /zit6/cmd/light
dvl_set (DVL控制)            →        /zit6/cmd/ins
```

#### 下行转换（micro-ROS → 上位机）
```
micro-ROS话题                →  转换  →  原始话题
─────────────────────────────────────────────────────
/zit6/state/pos (位置)       →        motion_controller.pos
/zit6/state/vel (速度)       →        motion_controller.imu.spd
/zit6/state/thr (推力)       →        motion_controller.thrust
/zit6/state/status (状态)    →        motion_controller (综合状态)
```

#### 心跳管理
- **发送心跳**：10Hz 向 micro-ROS 发送 `/zit6/cmd/agxhbt`
- **接收心跳**：监听 `/zit6/state/zithbt` 确认单片机在线
- **自动解锁**：心跳建立3秒后尝试系统解锁

#### 协议映射
- **6-DOF → 4-DOF**：将原系统的6自由度控制映射到新系统的4自由度
- **坐标系转换**：支持世界坐标系和机体坐标系切换
- **控制模式**：统一管理位置环/速度环/推力环三种控制模式

## 2. uv_hmu_no_serial.py（无串口上位机节点）

### 核心功能
**参数管理与话题转发** - 原有上位机节点的无串口版本，保持接口兼容性

### 主要职责

#### 参数管理
```
功能                    说明
─────────────────────────────────────────
PID参数加载            从JSON文件加载PID参数
PID参数保存            接收新参数并保存到文件
推力曲线加载           从JSON文件加载推力曲线
推力曲线保存           接收新曲线并保存到文件
参数广播               定期发布参数供其他节点使用（20Hz）
```

#### 话题转发
```
接收上层应用命令  →  发布到标准话题  →  由 bridge 转发到 micro-ROS
────────────────────────────────────────────────────────────
✓ 开环推力控制
✓ 位置控制
✓ 速度控制
✓ PID参数设置
✓ 舵机控制
✓ LED控制
✓ DVL控制
✓ 电磁铁控制
```

#### 状态接收
```
接收 bridge 反馈  →  更新本地数据  →  可供上层应用查询
──────────────────────────────────────────────────────
✓ 运动控制器状态（位置、速度、推力）
✓ 设备管理器状态（传感器、电池）
```

#### 兼容性保证
- **相同的话题接口**：上层应用无需修改代码
- **相同的消息类型**：使用原有的 `uv_msgs` 消息
- **相同的参数格式**：JSON文件格式保持不变

## 工作流程图

```
┌─────────────────┐
│   上层应用       │ (控制算法、界面等)
└────────┬────────┘
         │ uv_msgs 话题
         │
┌────────▼────────────────┐
│ uv_hmu_no_serial.py     │ 参数管理 + 话题转发
└────────┬────────────────┘
         │ uv_msgs 话题
         │
┌────────▼────────────────┐
│ microros_bridge.py      │ 协议转换 + 心跳管理
└────────┬────────────────┘
         │ zit6_interfaces 话题
         │
┌────────▼────────────────┐
│ micro-ROS (STM32)       │ 运动控制 + 传感器
└─────────────────────────┘
```

## 关键特性对比

| 特性 | microros_bridge | uv_hmu_no_serial |
|------|----------------|------------------|
| **主要功能** | 协议转换 | 参数管理 |
| **通信方向** | 双向 | 双向 |
| **消息转换** | ✓ | ✗ |
| **心跳管理** | ✓ | ✗ |
| **参数存储** | ✗ | ✓ |
| **参数广播** | ✗ | ✓ |
| **必需性** | 必需 | 可选* |

*注：如果上层应用直接使用 `zit6_interfaces` 消息，则不需要 `uv_hmu_no_serial`

## 使用场景

### 场景1：最小改动迁移（推荐）
```bash
# 启动桥接节点
ros2 run uv_bridge microros_bridge

# 启动参数管理节点
ros2 run uv_bridge uv_hmu_no_serial

# 原有上层应用无需修改，直接运行
```

### 场景2：完全重写
```bash
# 只启动桥接节点
ros2 run uv_bridge microros_bridge

# 上层应用直接使用 zit6_interfaces 消息
# 不需要 uv_hmu_no_serial
```
